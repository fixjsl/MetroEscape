## 촬영 시 주의

- cmd에서는 `^`가 이스케이프 문자이므로 `"71bc1e5^1"`처럼 따옴표로 감싼다. PowerShell은 불필요.
- `git config core.quotepath false`를 설정해야 한글 경로가 그대로 출력된다.
- 터미널 폭은 80열 전후로 좁혀 찍는다. 논문 본문 폭이 17cm이므로 100열 이상이면 줄이 접힌다.
- 명령줄이 화면에 함께 보여야 한다. 특히 B와 C의 빈 출력은 명령줄이 없으면 증거가 되지 않는다.

## 알려진 잡음

`B_3구역추가_디프.png`에 `Assets/Settings/PC_Renderer.asset`(2행)이 포함되어 있다. 3구역 작업과 무관한 렌더러 설정 변경이므로, 논문 표에 싣는다면 각주로 밝힌다.
