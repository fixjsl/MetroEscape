# MetroEscape (SubwayExit)

폐쇄된 지하철역에서 몬스터를 피하거나 처치하며 자원을 모으고, 비상구를 찾아 탈출하는 3D 서바이벌 액션 게임입니다. 졸업작품으로 개발 중이며, 현재는 데모 단계입니다.

> 현재 상태: 핵심 시스템은 동작하는 데모 단계이고, `리팩토링중` 브랜치에서 구조 리팩토링을 진행하고 있습니다.

## 개발 환경

| 항목 | 내용 |
|------|------|
| 엔진 | Unity 6000.3.26f1 |
| 렌더 파이프라인 | URP 17.3 (Render Graph) |
| 입력 | Unity Input System 1.20 |
| 언어 | C# |

## 게임 개요

- **장르**: 3D 서바이벌 액션 (횡방향 이동 기반)
- **목표**: 거점에서 출발해 구역을 탐색하고, 무작위로 배치되는 비상구를 찾아 탈출
- **진행 구조**: 사이클 방식. 사이클이 끝나면 몬스터, 상자, 유니크 드롭이 초기화되고 다시 거점에서 출발
- **메타 진행**: 처치 수, 수집 기록에 따라 퍽이 해금되고, 다음 플레이 시작 시 선택해 적용

## 주요 기능

### 전투
- 3타 콤보 공격, 회피, 가드, 패리, 처형
- 0.2초 입력 버퍼로 상태 전환 중에 들어온 입력도 놓치지 않음
- 캔슬 윈도우와 콤보 윈도우로 공격 연결 타이밍 제어

### 몬스터 AI
- 상태: Idle, Move, Chase, Battle, Attack, Hit, Stun, Return, Die
- 플레이어의 **소음**(걷기, 달리기, 웅크리기)과 **밝기**(손전등 사용 여부)를 기반으로 감지
- 보스는 일반 몬스터 상태 머신을 상속하고 특수 공격 상태와 전투 구역 로직을 추가

### 생존
- 배고픔, 갈증, 스태미나 관리
- 지속 효과 시스템(회복, 능력치 배율)과 효과 중첩 시 재적용 규칙

### 아이템
- 무게와 슬롯 제한이 있는 인벤토리
- 제작대 레시피, 캠프파이어, 정수기 등 상호작용 오브젝트
- 확정 드롭과 확률 드롭을 나눈 루트 테이블, 사이클당 한 번만 나오는 유니크 아이템

### 렌더링
- 손전등 효과를 URP `ScriptableRendererFeature`와 커스텀 셰이더로 구현
- 손전등 콘 안에 들어온 몬스터만 보이도록 처리 (`MaterialPropertyBlock`으로 머티리얼 인스턴스 생성 없이 알파 조절)
- 화면 공간 포인트 라이트 최대 4개를 전역 셰이더 배열로 전달

## 설계

### 제네릭 상태 머신
플레이어, 몬스터, 보스가 같은 상태 머신 구조를 공유합니다.

```
StateMachine<TState>   상태 등록, 조회, 전환 (Dictionary<Type, TState>)
State                  Enter / LogicUpdate / PhysicalUpdate / Exit, 전환 가능 여부
StateFactory           리플렉션으로 TState의 하위 클래스를 찾아 자동 생성 및 등록 (타입 목록 캐싱)
```

- `PlayerStateMachine` → `StateMachine<PlayerState>`
- `MonsterStateMachine` → `StateMachine<MonsterState>` (네임스페이스로 상태 필터링)
- `BossStateMachine` → `MonsterStateMachine` 상속 + `BossState` 추가

새 상태는 클래스만 추가하면 자동으로 등록됩니다. 플레이어는 이와 별도로 배고픔/갈증, 소음/밝기 같은 **패시브 상태**를 동시에 실행합니다.

### 그 밖의 구조
- **스탯 배율**: `StatModifierSet`이 같은 스탯의 버프 중 최댓값과 디버프 중 최솟값만 곱해서 중첩 폭주를 막음
- **UI 스택**: 열린 패널을 스택으로 관리해 ESC 처리, 일시정지, 전투 입력 차단을 한 곳에서 처리
- **저장**: `JsonFileStore`가 임시 파일에 쓴 뒤 교체하는 방식으로 저장 중 손상을 막고, 읽기 실패 시 `.bak`으로 백업 후 기본값 사용
- **캐싱**: 애니메이터 해시, 레이어, `WaitForSeconds`를 캐싱해 매 프레임 할당을 줄임

## 성능 측정

`PerfLogger`로 프레임 시간, 드로우콜, 배치, SetPass, 삼각형 수, GC 할당, 손전등 패스 시간을 수집해 CSV로 저장합니다.

- 측정할 씬에 붙이고 실행 후 `F9`로 시작
- 워밍업 구간(기본 5초)은 버리고, 지정 시간(기본 30초) 후 자동 종료
- 실행 인자 `-label <이름>`으로 빌드를 다시 하지 않고 조건별 결과를 구분

## 폴더 구조

```
Assets/Script/
├── StateMachine/   제네릭 상태 머신, 상태 팩토리
├── Player/         플레이어 상태, 장비, 인벤토리, 패시브
├── Monster/        몬스터 상태, 감지, 무기
├── Boss/           보스 상태 머신, 전투 구역
├── Stats/          플레이어, 몬스터, 무기 스탯과 배율
├── Effects/        지속 효과
├── Items/          아이템, 루트 테이블, 레시피
├── Meta/           메타 진행, 퍽
├── World/          문, 상자, 제작대 등 상호작용 오브젝트와 게이트
├── UI/             HUD, 창, 시작 메뉴, 시스템 UI
├── Rendering/      손전등 렌더러 피처, 포인트 라이트
├── Core/           게임 매니저, 사이클, 입력, 저장, 유틸
├── Tutorial/       튜토리얼 흐름
└── Measurement/    성능 측정
```

## 실행 방법

1. Unity 6000.3.26f1로 프로젝트를 엽니다.
2. `Assets/Scenes/StartMenuScene`을 열고 실행합니다.

### 조작

| 키 | 동작 |
|----|------|
| 이동 | 좌우 이동 |
| 공격 | 콤보 공격 |
| 회피 | 회피 |
| 가드 | 가드 (무기 장착 시 패리 입력) |
| 웅크리기 | 웅크리기 전환 |
| 달리기 | 누르는 동안 달리기 |
| 상호작용 | 문, 상자, 아이템 등 |
| 손전등 | 켜기/끄기 |
